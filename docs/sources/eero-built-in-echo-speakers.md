## What eero Built-in does

Echo speakers identified as supporting **eero Built-in** can act as extenders for an existing eero mesh network. The supplied excerpt describes a maximum of up to 1,000 square feet of additional coverage, speeds up to 100 Mbps, and connections for up to 10 devices per compatible Echo. It says these Echo extenders use 5 GHz Wi-Fi, not 2.4 GHz or 6 GHz. These are stated product limits, not guaranteed real-world performance.

The feature is not available everywhere; the supplied article says it is available in the United States and Canada. It requires a compatible eero gateway (the main router) and a compatible Echo speaker. An Echo is not automatically a mesh node just because it is an Echo: look for current eero Built-in support for the exact model and region.

## Requirements and updates

Before setup, the excerpt recommends:

- Updating the eero system, Alexa app, and Echo software.
- Using eero software version 6.12.1 or later, as stated in the article.
- Using the same Amazon account for eero, Echo devices, and the Alexa app.
- Connecting the Echo speakers and eero network to the same Wi-Fi network.
- Linking the Amazon and eero accounts if they use separate sign-in credentials.

To check for eero software updates, the article says to open the eero app and go to **Settings > Software version**. Update the Alexa app through the device's app store. Ask an Echo, “Alexa, check for software updates,” to check Echo software.

## Linking accounts

If the Amazon and eero accounts are not already linked, the supplied excerpt gives these app steps:

1. Open the eero app and choose **Discover**.
2. Choose **Amazon Connected Home**.
3. Choose **Connect to Amazon** and review the prompt.
4. Sign in with the Amazon account to link the accounts.

App labels can change between versions.

## Enabling eero Built-in

After updates and account linking:

1. Open the eero app and go to **Discover > Amazon Connected Home**.
2. Choose **eero Built-in** and switch it on.
3. Select the listed compatible Echo speakers to enable as extenders.
4. View the active eero routers, nodes, and enabled Echo devices in the eero app's network view.

According to the supplied article, compatible Echo devices added later may extend the network automatically once eero Built-in is enabled. The article recommends using no more than four Echo extenders for best results.

## Planning notes

- Use an Echo extender to improve coverage where it can still maintain a good connection to the eero network; placement and building conditions affect results.
- The stated 1,000-square-foot maximum, 100-Mbps speed, and 10-device limit are not promises of performance in every home.
- Because the Echo extender in the supplied excerpt uses 5 GHz only, it should not be assumed to extend 2.4-GHz or 6-GHz coverage.
- This extends an eero network; it is not described as a general-purpose extender for arbitrary router brands.
- If streaming or theater playback remains unreliable, check network conditions and device placement as well as the speaker's eero Built-in status.
